## Про репозиторій

Цей репозиторій містить виконані домашні завдання з курсу **основ Linux та роботи в терміналі**. Кожен модуль охоплює окрему тему — від базових команд оболонки до адміністрування системи.

Усі завдання виконані в середовищі **Ubuntu**, результати підкріплені скріншотами терміналу.
